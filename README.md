# Unbrick

Unbrick is a native SwiftUI iPhone app for learning Korean (KIIP 중급 1). Lessons, quizzes, review, a calendar, and an AI tutor sit behind a lock screen: practice to earn a short unlock window.

This repository starts from the original Xcode project (`Unbrick/`). Open `Unbrick/Unbrick.xcodeproj` in Xcode.

The app target is the synchronized folder `Unbrick/Unbrick`. Textbook JSON used by the app is `Unbrick/Unbrick/Resources/Content.json`. Per-unit source files live in `Unbrick/content/`. A browser prototype is `Unbrick/web/unbrick.html`.
