Unbrick privacy policy

Unbrick (App Store name “Unbrick: Learn Korean”) is a Korean study app from IMEX Global, bundle id com.imexglobalintl.unbrick. Contact: hellopawfend@gmail.com. Last updated 23 October 2026.

There is no Unbrick account. The app does not ask for your name, email, phone number, contacts, photos, or location. It does not show ads, and it does not track you across other companies’ apps or websites.

What stays on this iPhone

  • Study progress is a file in the app’s local storage: scores, streak, the unit you are on, the goal and date you set, cards you added, and which practice tiles you marked. It is not uploaded.
  • If you create a Screen Time passcode in Unbrick, that code is stored in the iOS Keychain on this iPhone. It is not sent to IMEX Global or Anthropic.
  • The app creates a random id for this install and stores it in the Keychain. It is not the advertising identifier and not the device vendor id.
  • When you speak an answer, Unbrick writes a short recording in a temporary file so you can play it back. iOS clears temporary files. That audio file is not uploaded to the Unbrick server.

Microphone and speech

The microphone is used so you can speak Korean answers. Apple’s Speech Recognition turns that audio into text. When this iPhone supports on-device recognition for Korean, Unbrick requires on-device recognition, so the audio stays on the phone. When it does not, Apple’s speech service may receive the audio. Unbrick does not send the audio file to its own server.

Korean text you tap to hear is spoken by Apple’s on-device voice.

AI tutor and grading

When this build includes the Unbrick server, the text of your answer and the lesson prompt (not the audio) are sent to that server with the install id. The server forwards that text to Anthropic’s Claude API and returns the feedback. The server does not store the prompt, the answer, or the reply.

The server uses your IP address only as a one-minute rate-limit counter in memory. It does not save the IP as a profile and it does not turn it into a location. The install id is stored with a daily message count and with the shared spend total, so the tutor can stop at the daily cap. Message text is not stored with it. Daily install-id counts are dropped after a few days. The spend total is one number for the whole service, not a record of who you are.

If the server’s budget is used up, or this build has no server, and Apple Intelligence is available, grading can run on the device. That on-device pass is not sent to Anthropic.

Anthropic’s terms apply to text that reaches Claude. See Anthropic’s privacy policy.

Notifications

If you allow notifications, Unbrick schedules one local alert for the moment an unlock timer ends. There is no remote push, and Unbrick does not receive a push token.

Practice tiles and Screen Time

Tiles named for other apps are practice shortcuts inside Unbrick. Tapping one does not close or shield that app. This build does not use Apple’s Family Controls API. Limiting other apps is something you can set up yourself in iOS Settings under Screen Time. Unbrick can store the passcode you create and show it after you finish a practice session.

Android

The Android scaffold, if you install it, sends the same kind of tutor text and an install id to the same server. It does not block other apps. It is not the App Store app.

Children

Unbrick is not directed at children under 13. Do not use it for a child if you are not comfortable with speech recognition and, when the server is on, answer text being sent as described above.

Deletion

There is no account to delete. Delete the app to remove on-device progress, the passcode, the install id, and temporary recordings. The server has no profile to erase. Email hellopawfend@gmail.com if you want to ask what the server holds.

Tracking

Unbrick does not track you, does not use the advertising identifier, and does not use your data for advertising.
