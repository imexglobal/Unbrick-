Unbrick privacy policy

Unbrick is a Korean study app. This policy covers the iOS app, the Android scaffold, and the small server that asks Claude for feedback. The operator is [legal name of the developer or company], the owner of bundle id com.imexglobalintl.unbrick. Contact: [support email].

What stays on your phone

  • Study progress (scores, streak, the unit you are on, cards you added) is stored in the app’s files on the device.
  • If you create a Screen Time passcode inside Unbrick, it is stored in the iOS Keychain on that device. It is not sent to the server.
  • A short microphone clip is saved in a temporary file so you can replay what you said. The operating system clears temporary files.
  • There is no Unbrick account. The app does not ask for your name, email, contacts, photos, or location.

Microphone and speech

The microphone is used so you can speak Korean answers. Speech Recognition turns that audio into text. When the Korean on-device speech model is installed, recognition stays on the device. When it is not, Apple’s speech service may receive the audio. Unbrick does not upload the audio file to its own server.

Claude

Some builds send the text of your answer and the lesson prompt to an Unbrick server, which forwards them to Anthropic’s Claude API and returns the feedback. The server is built not to store the prompt, the answer, or the reply. It does use your IP address for a short rate limit so the API key cannot be abused. The Anthropic API key is only on the server. It is not in the app.

Until that server address is configured, the iOS app does not call Claude. If Apple Intelligence is on, grading can happen on the device instead, and that text is not sent to Anthropic.

Anthropic’s own terms apply to text that reaches Claude. See Anthropic’s privacy policy.

Notifications

If you allow notifications, Unbrick schedules one local notification for the moment an unlock window ends. Unbrick does not use remote push, and it does not run an advertising or analytics SDK.

App blocking

On iOS, blocking other apps is done by Screen Time, which you turn on yourself. A direct block from inside Unbrick needs Apple’s Family Controls entitlement. That entitlement is not enabled in the project until Apple approves it. App selections for Family Controls, once that ships, stay on the device. On Android, the scaffold does not block other apps.

Children

Unbrick is not directed at children under 13, and it is not a school product. Do not use it for a child if you are not comfortable with speech recognition and, when Claude is enabled, text being sent to the server described above.

Retention and deletion

Delete the app to remove on-device progress and the Keychain passcode entry. The server does not keep a profile to delete. Rate-limit counters expire within about a minute.

Tracking

Unbrick does not track you across other companies’ apps or websites, and it does not use your data for advertising.
